# C17-l5: Data, Averages and Spread: Coding Data

Status: done
Branch: `claude/under30-three-singles-m94jmr`

Level `da-l5` in course `data-averages-spread`, 5 lessons (Adding a Constant, Multiplying by a Constant, Coding and Decoding, Variance from Coded Sums, Coding in Context), a level check of 15 questions, 20 new generators (`dat-code-*`), seven of them with a `+choice` form.

Every statistic is exact by construction: a coded mean and standard deviation are drawn first and the sums built from them, so nothing is rounded. `dataAveragesSpread.test.ts` checks each answer on a list built to have the stated statistics, changed or decoded value by value, never by the rules the lessons teach. The two tree generators are `dat-code-bxc-tree` and `dat-code-var-tree` rather than `-linear-tree` and `-sums-tree`, since `familyOf` strips `-tree` and would have counted them as a second ask of `dat-code-linear` and `dat-code-sums`.

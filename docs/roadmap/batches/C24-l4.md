# C24-l4: Geometry: Scaling

Status: done
Branch: `claude/geometry-course-sdjq9m`

Level `geo-l4`, 2 lessons (`geo-l4-shapes`, `geo-l4-lengths`) and a
10-question level check; 8 generators in `generators/geometryScaling.ts`.

- Similar triangles are drawn side by side on one baseline and to one scale.
- Scale factors are 2 or 3, or 1.5, 2.5 and 0.5 on even sides, so every
  length is whole.
- "15 cm by 32 cm" is read by value as an area in the option check, so the
  similar-rectangle options never share an area.

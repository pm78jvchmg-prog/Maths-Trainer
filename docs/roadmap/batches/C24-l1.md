# C24-l1: Geometry: Angles

Status: done
Branch: `claude/geometry-course-sdjq9m`

New course `geometry` (Algebra Fundamentals band, position 75, before
Coordinate Geometry), plan in `docs/roadmap/levels/geometry.md`. Level
`geo-l1`, 3 lessons (`geo-l1-lines`, `geo-l1-parallel`, `geo-l1-triangles`)
and a 12-question level check, 12 new `geo-*` generators in
`generators/geometryAngles.ts`, shared SVG pieces in
`generators/geometryKit.ts`.

- Owner's rule: every formula given before use, every diagram labels the
  angles the question needs, with the unknown drawn in the accent colour.
- Levels live in `courses/geometry/levelN.ts`, imported by the one course
  file, so later levels can be written side by side.
- Choice options are rotated by a hash of the question, never shuffled.

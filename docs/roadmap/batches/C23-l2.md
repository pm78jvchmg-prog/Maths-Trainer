# C23-l2: Classical Mechanics: Motion in Two Dimensions

Status: done
Branch: `claude/classical-mechanics-course-i7qlc4`

Level `clm-l2`, 5 lessons (`clm-l2-horizontal`, `clm-l2-angle`,
`clm-l2-angular`, `clm-l2-angacc`, `clm-l2-centripetal`) and a 12-question
level check; 20 generators in `generators/classicalTwoD.ts`.

- Fall times in halves give heights 4.9t^2; a vertical speed 4.9k flies for
  exactly k seconds. Launch angles come from Pythagorean triples.
- `classicalTwoD.test.ts` steps each flight and each spin-up in small time
  steps rather than using the generator's formulas.

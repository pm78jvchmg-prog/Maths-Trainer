# C23-l8: Classical Mechanics: Springs

Status: done
Branch: `claude/classical-mechanics-course-i7qlc4`

Level `clm-l8`, 5 lessons (`clm-l8-together`, `clm-l8-well`, `clm-l8-shm`,
`clm-l8-pendulum`, `clm-l8-swing`) and a 12-question level check; 20
generators in `generators/classicalSprings.ts`.

- Speeds come from Pythagorean triples scaled by a step, so every square
  root is exact; pendulums use g = 9.8 with lengths chosen so the angular
  frequency is a short decimal.
- `classicalSprings.test.ts` checks springs by the force in each part,
  speeds by stepping the motion in time, pendulum frequencies by stepping a
  small swing, and large swings by the full pendulum equation.

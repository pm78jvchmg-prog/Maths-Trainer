# Inspiration

Screenshots of Brilliant, captured on an iPhone, plus a few of this app for
comparison. They are the reference for the lesson shape, the slide kinds and
the feedback bar — not a style guide to copy pixel for pixel.

Two things in here are deliberately **not** reproduced:

- **The XP counters.** `+15 XP` on the feedback bar and the running total in the
  header. This is a single-player practice tool with no engagement mechanics;
  see the rule in `CLAUDE.md`.
- **The 3D isometric artwork.** The app is an offline PWA with no runtime
  network access, so illustrations have to be inline SVG rather than rendered
  assets pulled from a CDN.

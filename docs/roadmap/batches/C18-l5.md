# C18-l5: Binomial & Normal Distributions: Sums and Differences of Independent Normals

Status: done
Branch: `claude/roadmap-c18-binomial-normal-l5-h6yus8`

Level `bn-l5` in course `binomial-normal`, 5 lessons (Scaling and Shifting: aX + b, X + Y and X − Y, aX + bY in General, A Total of n Copies, A Probability from the Combination), a level check of 15 questions, 20 new generators (`dist-lin-*`, `dist-sum-*`, `dist-combo-*`, `dist-total-*`, `dist-bigger-prob`, `dist-diff-*`).

Level 4 had landed on main when this started, so it branches from main.

- Every combination aX + bY is built from a Pythagorean triple (a σ_X and |b| σ_Y are its legs), so the combined variance is a perfect square and σ is whole; a draw that is not is refused. A probability question uses only the triples whose hypotenuse divides 100, so every whole boundary gives a z of at most two places.
- A total of n copies uses n in 4, 9, 16, 25, so nσ² is a square too. The total-or-scaled flow says "once" in every scaled setting and never in a copies one, which is how the test tells them apart.
- Independence is pointed at in the Probability course (`pb-l2-independence`), not taught again.
- `binomialNormal.test.ts` reads every distribution, coefficient, count and quoted Φ back out of each prompt, works E, Var, σ and each probability out itself, and holds each probability to the quoted Φ and within 0.001 of Simpson. Three planted mistakes (a flipped P(X > Y), a subtracted variance for X − Y, a negative σ for aX + b) each turned it red.
